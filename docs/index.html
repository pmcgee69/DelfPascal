Delf

Delphi with a modern, functional-influenced type system, transpiling to plain Delphi.

A Delf file is Delphi with additions of syntax and code-correctness: sum types and pattern matching in place of nil and sentinel values, tuples, lambdas with inferred types, no implicit conversions, exhaustive cases. A transpiler, delfc, turns it into readable, standard Delphi that a Delphi programmer could have written by hand and can step through in the debugger.

WriteLn('passed: ', Scores.Filter(IsPass).Map(.ToString).Join(', '));

// the plain Delphi it stands for, with Shown(N) answering N.ToString
WriteLn('passed: ', TArrays.Join(
                        TArrays.Map<Integer, string>(
                            TArrays.Filter<Integer>(Scores, IsPass), Shown), ', '));

Rename any Delphi file to .delf and nothing changes but some extra checks. delfc is tested on over 17,000 files of real Delphi. The design filter is better safety without red tape: a safety rule that makes the writer repeat themselves is a sign the syntax is missing something.
